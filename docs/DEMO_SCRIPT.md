# 60-second demo script (screen recording, no slides)

0–8s  Problem. "A tenant texts: 'boiler's dead and there's water under it'. Today a
      property manager spends ~3 hours per repair on calls, lookups and chasing."
8–20s Show the case folder (message + CRM record + repair history). Run one command.
20–40s Show the terminal trace: property looked up, repair history shows same fault
      twice, policy says heating loss with vulnerable tenant = urgent, contractor
      searched, booked, tenant and landlord messaged. (Voice: the outbound call to
      the contractor confirming the slot — play 5s of it.)
40–50s Open ANSWER.md: outcome, actions, escalation = none, confidence.
      Flip to a second case: gas smell -> agent refuses to book, escalates with a
      full handover packet, tells tenant to call the gas emergency line.
50–60s "Resolve AI: from 'something's broken' to 'it's being fixed', and it knows
      when to stop and ask a human. Built on Claude + ElevenLabs. Repo link."
